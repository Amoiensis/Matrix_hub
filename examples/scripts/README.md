# 脚本示例

本目录保存 MatrixHub CLI 可直接执行的 `.m` 示例。

其他语言: [English](README.en.md) / [日本語](README.ja.md)

运行：

```bash
./build/Matrix_Hub_v2_0_cli examples/scripts/basic.m
./build/Matrix_Hub_v2_0_cli examples/scripts/range.m
./build/Matrix_Hub_v2_0_cli examples/scripts/slice.m
./build/Matrix_Hub_v2_0_cli examples/scripts/multi_output.m
```

示例覆盖矩阵字面量、范围、索引/切片、`if/elif/else`、`for` 循环、多输出分解和变量管理命令。
