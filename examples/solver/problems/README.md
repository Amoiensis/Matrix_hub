# solver problems

本目录只保留发布版内置的小型 `.lp` 问题。

其他语言: [English](README.en.md) / [日本語](README.ja.md)

| 文件 | 说明 |
| --- | --- |
| `ortools_mip.lp` | Google OR-Tools MIP 小示例 |
| `ortools_mip_array.lp` | Google OR-Tools array MIP 小示例 |
| `lpp0033.lp` | MIPLIB3 `p0033` 转换文件 |
| `gt2.lp` | MIPLIB3 `gt2` 转换文件 |

其他较大的 benchmark 不放进 Git；下载来源见上级目录 [README](../README.md)。
