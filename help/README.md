# help

本目录保存 MatrixHub 的帮助主题，CLI 中的 `help <topic>` 会优先查找这里的文件。

其他语言: [English](README.en.md) / [日本語](README.ja.md)

按使用场景查询：

| 场景 | 推荐主题 |
| --- | --- |
| C 函数/API | `help M_mul`, `help M_QR`, `help c_library` |
| 命令行计算器 | `help`, `help script_mode`, `help script_commands`, `help script_functions` |
| LP/MIP solver | `help solver_mode`, 或运行 `Matrix_Hub_v2_0_solver --help` |

常用主题：

```text
help MatrixHub
help script_mode
help solver_mode
help c_library
help M_mul
help M_Inverse
help M_QR
help M_SVD
```

`M_*.txt` 文件对应具体 C API 或脚本函数；命令类说明集中在 `script_commands.txt` 和 `script_functions.txt`。
