# Script Examples

This directory contains `.m` files that can be executed by the MatrixHub CLI.

Other languages: [中文](README.md) / [日本語](README.ja.md)

```bash
./build/Matrix_Hub_v2_0_cli examples/scripts/basic.m
./build/Matrix_Hub_v2_0_cli examples/scripts/range.m
./build/Matrix_Hub_v2_0_cli examples/scripts/slice.m
./build/Matrix_Hub_v2_0_cli examples/scripts/multi_output.m
```

The examples cover matrix literals, ranges, indexing/slicing, `if/elif/else`, `for` loops, multi-output decompositions, and workspace commands.
