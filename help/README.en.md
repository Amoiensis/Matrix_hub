# help

This directory contains MatrixHub help topics. The CLI command `help <topic>` looks up these files first.

Other languages: [中文](README.md) / [日本語](README.ja.md)

Use help by context:

| Context | Suggested topics |
| --- | --- |
| C API | `help M_mul`, `help M_QR`, `help c_library` |
| CLI calculator | `help`, `help script_mode`, `help script_commands`, `help script_functions` |
| LP/MIP solver | `help solver_mode`, or run `Matrix_Hub_v2_0_solver --help` |

`M_*.txt` files document individual C APIs or script functions. Command-level topics live in `script_commands.txt` and `script_functions.txt`.
