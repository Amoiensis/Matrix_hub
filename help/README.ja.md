# help

このディレクトリには MatrixHub の help トピックを置きます。CLI の `help <topic>` はまずこれらのファイルを参照します。

他の言語: [中文](README.md) / [English](README.en.md)

利用場面ごとの例：

| 場面 | 推奨トピック |
| --- | --- |
| C API | `help M_mul`, `help M_QR`, `help c_library` |
| CLI 計算器 | `help`, `help script_mode`, `help script_commands`, `help script_functions` |
| LP/MIP solver | `help solver_mode`、または `Matrix_Hub_v2_0_solver --help` |

`M_*.txt` は個別の C API やスクリプト関数を説明します。コマンド関連は `script_commands.txt` と `script_functions.txt` にまとめています。
